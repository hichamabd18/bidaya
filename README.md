# اليوم النبوي ووظائف العام

الدليل الشامل للاقتداء والتعبد وتزكية النفس وفق السنن النبوية الشريفة ووظائف مواسم العام ومتتبع العادات الإيمانية.

تطبيق ويب عربي (RTL أولًا) يعمل كـ PWA: مسار اليوم النبوي محطةً محطة، وظائف الشهور الهجرية، مكتبة السنن والأدعية والقواعد، متتبع أوراد يومي/أسبوعي/شهري، مسبحة تفاعلية، ومواقيت صلاة فلكية لكل ولايات الجزائر (58) ومدن إسلامية مختارة — كل ذلك دون خادم أو حساب.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # إنتاج (Turbopack)
npm run lint       # ESLint (flat config)
npm run typecheck  # tsc --noEmit
npm test           # اختبارات ذهبية للمواقيت والتقويم
```

## قرارات هندسية موثّقة

- **مواقيت الصلاة**: فلكية خالصة بزوايا وزارة الشؤون الدينية الجزائرية (الفجر 18°، العشاء 17°، العصر بمقدار ظل الجذر). تُحلّ إزاحة التوقيت لكل تاريخ من معرّف IANA عبر `Intl` — فتتحقق القاهرة والقدس (التوقيت الصيفي) وأي موقع GPS على صواب. **ملاحظة**: القيم بلا «احتياط الوزارة»؛ قد تجد جداول رسمية فجرًا متأخرًا ~10-20 دقيقة بحسب المعايير المحلية.
- **التقويم الهجري**: أُبقيت الخوارزمية الجدولية السابقة عمدًا (لا تتغير التواريخ الشرعية المعروضة) مع معايرة الرؤية ±2 يوم في الإعدادات. بديل المنصة `Intl islamic-umalqura` متاح عند الحاجة.
- **الاستمرارية**: `bidaya.v1:*` — سجلات مفاتيحها دورية (`day:2026-09-25`، `week:2026-W39`، `month:…`) فلا يُمحى تقدّم الأسبوع بانتهاء اليوم، مع أرشيف 30 يومًا في «تقدمي» وقصّ تلقائي بعد 120 يومًا.
- **العزلة الزمنية**: نبضة الدقيقة في الموفّر لكل الحسابات، وساعة الثانية عبر `useSyncExternalStore` تُحدّث العدّاد فقط — لا تصيير كامل كل ثانية.
- **المظهر**: آلية واحدة (`data-theme`) تُطبَّع قبل الترطيب (لا وميض أبيض)، و«فجر»: لون الصفحة يتبع محطة اليوم عبر `data-daypart`.
- **إمكانية الوصول**: كل صف صفحة مفردة بزري تحكم مسمّيين، ورقة علوية واحدة بفخ تركيز وEscape وقفل تمرير، أهداف لمس ≥ 44px، تباينات موثقة في `globals.css` (نص 4.5:1+، عناصر 3:1+)، وحركة مقيّدة بـ `prefers-reduced-motion`.
- **الخطوط**: مستضافة ذاتيًا (Fontsource) — IBM Plex Sans Arabic للواجهة (400–700) وAmiri للنص الشرعي (400/700) بلا طلبات خارجية ولا انزياح تخطيط.

## انحرافات عن تقرير التدقيق (متعمّدة)

1. `adhan` لم يُضَف: إصلاح الإزاحة عبر `Intl` (قدرة منصة) يعالج العلّة الفعلية دون تغيير رياضيات مجرَّبة، ويحفظ واجهة `PrayerTimesResult` كما هي.
2. ميزة «تصدير ملف HTML واحد» أُزيلت: كانت تُنتج ملفًا معطوبًا (SyntaxError) يعتمد شبكات خارجية وبهوية بصرية مغايرة. تعود لاحقًا بأنبوب esbuild حقيقي بعد استقرار الهوية.
3. TypeScript يبقى 5.9: واجهة TS 7.0 البرمجية غير كافية لـ typescript-eslint حتى 7.1.
